# 林明 | Systems Engineer Portfolio

システムエンジニア向けのポートフォリオサイトです。PC・スマートフォン（SP）両対応のレスポンシブデザインで、実績（プロジェクト）を追加できる仕組みを備えています。

## ファイル構成

```
/
├── index.html   … ポートフォリオ本体（プロフィール・スキル・実績・お問い合わせ）
├── admin.html   … 実績を追加するためのフォームページ
└── README.md    … このファイル
```

CSSとJavaScriptはすべて `index.html` / `admin.html` 内に記述しているため、この2ファイルをそのままリポジトリに置くだけで動作します。

## GitHub Pages への公開方法

1. `dannyshine1028/My_Portfolio` リポジトリのルートに `index.html`（と `admin.html`）を配置してコミット・プッシュします。
2. GitHub の **Settings → Pages** を開き、Source を `main` ブランチ / `/(root)` に設定します。
3. 数分後、`https://dannyshine1028.github.io/My_Portfolio/` で公開されます。

## 実績（作品）の追加方法

このサイトは静的サイトのため、サーバー保存のアップロード機能は持てません。代わりに2つの方法を用意しています。

### 方法A：admin.html から追加してコードをコピー（推奨）
1. `admin.html` を開き、フォームに実績を入力します。
2. 入力内容はブラウザに一時保存され、`index.html` を開くとすぐにプレビューできます。
3. ページ下部に生成される **コード** をコピーし、`index.html` 内の `worksData` 配列の末尾に貼り付けます。
4. 変更をコミット・プッシュすると、全世界に公開されます。

> ブラウザに一時保存される内容（`localStorage`）は自分の端末にしか残らず、他の人には見えません。必ずコードをコピーして `index.html` に反映してください。

### 方法B：index.html を直接編集
`index.html` 内の `<script>` にある `worksData` 配列に、以下の形式でオブジェクトを追加します。

```js
{
  version: 'v1.0.0',
  date: '2026-08',
  status: 'PROD', // PROD / BETA / ARCHIVED
  title: 'プロジェクト名',
  description: '概要・成果',
  tags: ['AWS', 'Docker'],
  link: 'https://example.com' // 任意
}
```

## 掲載情報について（プライバシーに関する注記）

いただいた情報のうち、**番地までの詳細な住所は公開ページには掲載していません**。市区レベル（台北市 中山区）のみを表示しています。これは、個人の住所をインターネット上に公開すると、詐欺・ストーカー等のリスクにつながる可能性があるためです。契約時など、詳細な住所が必要な場合はメール（itprosomething@gmail.com）でのやり取りをおすすめします。

もし詳細住所の掲載を希望される場合は、`index.html` の `spec-list` および `json-card` 内の `location` の値を書き換えることで追加できます。

## カスタマイズのポイント

- **写真**：現在はイニシャル「林」のプレースホルダーです。`.avatar` を `<img>` タグに置き換えれば実写真に変更できます。
- **スキル**：`index.html` 内の `skillGroups` 配列を編集してください。
- **配色・フォント**：`:root` 内のCSS変数（`--accent-signal` など）を変更すると全体の配色が変わります。
- **文言**：日本語を主言語にしています。英語版が必要な場合はお知らせください。
